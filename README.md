# Guàrdies

Aplicació independent per gestionar les guàrdies de l'IES Josep Sureda i Blanes.

Comparteix el projecte de Firebase amb QUOTA per consultar cursos, professorat i usuaris, però disposa de repositori, versions, proves, desplegament i domini propis.

## Desenvolupament

```bash
npm install
npm run dev
```

## Verificació

```bash
npm run test:domain
npm run test:visual
npm run build
```

## Producció

- Domini: `guardies.iessureda.com`
- Plataforma: Netlify
- Firebase compartit: `quota-e1424`

Les regles de Firebase es gestionen des del repositori de QUOTA per evitar desplegaments en conflicte.
